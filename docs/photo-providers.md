# Источники фотографий SHODI

## Подключённые открытые источники

- Wikimedia Commons: P18 Wikidata и явные ссылки на файл из OSM. Только проверенная лицензия и авторство, HTTPS, допустимый формат и размер. При сомнении — иллюстрация категории. Сведения о сторонних правах требуют проверки перед коммерческой публикацией.
- OpenStreetMap: © OpenStreetMap contributors, ODbL 1.0 (https://www.openstreetmap.org/copyright). Отдельная адаптированная база public/data/osm-photo-links.js, предоставляемая на тех же условиях. Импорт scripts/import-osm-photo-links.mjs использует Overpass VK Maps (https://maps.mail.ru/osm/tools/overpass/api/interpreter), фильтрует явные File-ссылки и идентификаторы Wikidata, сопоставляет имя и координаты. Данные Overture не перелицензируются. Статистика docs/osm-photo-coverage.json отражает ссылки, а не гарантированное количество доступных фотографий.

## Дополнительный бесплатный поиск

Commons Geosearch: https://commons.wikimedia.org/wiki/Commons:Search_by_location — поиск геопривязанных файлов в радиусе 100 метров. Используется только при отсутствии подтверждённого фото объекта, с явной подписью «Фото рядом с местом (не самого объекта)», указанием автора, лицензии и источника. Это фотография окрестностей, не доказательство внешнего вида заведения.

Mapillary: https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data — свободные снимки с улиц, API требует собственный токен; не подключён. KartaView: https://kartaview.org/terms (раздел 4), CC BY-SA 4.0, © Grab and KartaView Contributors. Публичный API https://kartaview.org/doc/photos и https://kartaview.org/doc/faq; до 100 запросов в час без ключа. Приложение использует не более 80 запросов в час на устройство, только активные публичные обработанные снимки (BLURRED, FINISHED) до 100 м от места и миниатюры с допустимого HTTPS storage-хоста, с авторством, ссылкой, датой и явной пометкой окрестностей. Покрытие, живые HTTP/CORS и действительные ответы проверяются в CI на диагностической выборке; нулевое покрытие не считается успешным покрытием. 

## Ограничения проекта

Только бесплатные открытые источники, без платных договоров и парсинга Яндекс Карт/2ГИС. По состоянию на текущую версию нет подтверждённого бесплатного источника фотографий почти всех коммерческих заведений. Наличие фото и права на конкретные изображения не гарантируются. Категорийные иллюстрации не учитываются в статистике фотографий.
