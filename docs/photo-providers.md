# Источники фотографий SHODI

## Подключённые открытые источники

- Wikimedia Commons: P18 Wikidata и явные ссылки на файл из OSM. Только проверенная лицензия и авторство, HTTPS, допустимый формат и размер. При сомнении — иллюстрация категории. Сведения о сторонних правах требуют проверки перед коммерческой публикацией.
- OpenStreetMap: © OpenStreetMap contributors, ODbL 1.0 (https://www.openstreetmap.org/copyright). Отдельная адаптированная база public/data/osm-photo-links.js, предоставляемая на тех же условиях. Импорт scripts/import-osm-photo-links.mjs использует Overpass VK Maps (https://maps.mail.ru/osm/tools/overpass/api/interpreter), фильтрует явные File-ссылки и идентификаторы Wikidata, сопоставляет имя и координаты. Данные Overture не перелицензируются. Статистика docs/osm-photo-coverage.json отражает ссылки, а не гарантированное количество доступных фотографий.

## Дополнительный бесплатный поиск

Commons Geosearch: https://commons.wikimedia.org/wiki/Commons:Search_by_location — поиск геопривязанных файлов в радиусе 100 метров. Используется только при отсутствии подтверждённого фото объекта, с явной подписью «Фото рядом с местом (не самого объекта)», указанием автора, лицензии и источника. Это фотография окрестностей, не доказательство внешнего вида заведения.

Mapillary: https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data — свободные снимки с улиц, API требует собственный токен; не подключён. KartaView: https://kartaview.org/terms (раздел 4), CC BY-SA 4.0, © Grab and KartaView Contributors. Публичный API https://kartaview.org/doc/photos и https://kartaview.org/doc/faq; до 100 запросов в час без ключа. Приложение использует не более 80 запросов в час на устройство, только активные публичные обработанные снимки (BLURRED, FINISHED) до 100 м от места и миниатюры с допустимого HTTPS storage-хоста, с авторством, ссылкой, датой и явной пометкой окрестностей. Покрытие, живые HTTP/CORS и действительные ответы проверяются в CI на диагностической выборке; нулевое покрытие не считается успешным покрытием. 

## Ограничения проекта

Только бесплатные открытые источники, без платных договоров и парсинга Яндекс Карт/2ГИС. По состоянию на текущую версию нет подтверждённого бесплатного источника фотографий почти всех коммерческих заведений. Наличие фото и права на конкретные изображения не гарантируются. Категорийные иллюстрации не учитываются в статистике фотографий.

## Логотипы всех распознанных брендов
Поле brand.names.primary / brand.wikidata извлекается из того же выпуска Overture по точному идентификатору места (SHA-256, существующий ключ каталога), без порога количества филиалов. При сборке Android формируется public/data/place-brands.js; отдельный отчёт и база сохраняются в артефакте CI. P154 Wikidata либо проверенный файл Commons, только разрешённые CC или явно обозначенное public domain с метаданными. SVG не исполняется, загружается только растровая миниатюра. Отдельная пометка «Логотип бренда», общий кеш на бренд, отсутствие связи с рекламой. Статус Commons не снимает охрану товарных знаков и не гарантирует законность в каждой юрисдикции; проверить до подписанного релиза. Нет минимального числа филиалов; неизвестный бренд/неясная лицензия — без логотипа. Встроенные фотографии сохраняются.

При Android-сборке отдельно проверяются все выявленные брендовые ключи и скачиваются разрешённые растровые миниатюры (scripts/import-brand-logos.mjs). Реальные файлы и отчёт docs/brand-logo-coverage.json включены в артефакт shodi-brand-coverage. Отдельный smoke-тест проверяет отображение фактически скачанного логотипа без сети. Нулевая загрузка логотипов не считается успешной сборкой. Импорт ограничен по времени, учитывает Retry-After, не обходя лимиты; недоступные и непроверенные бренды отражены в отчёте.

### Повторные сборки
Связи брендов кешируются по точной версии исходного каталога и импортёра; ранее проверенные логотипы сохраняются между сборками с одинаковой версией правил импорта. Явные QID и известные файлы обрабатываются первыми, названия без QID сопоставляются пакетами Wikidata SPARQL, при конфликте кандидатов логотип не назначается. Отчёт и манифест сверяются с каталогом до компиляции. Ограничения API и непроверенные бренды не маскируются статусом сборки.

### Проверенные дополнительные связи
При отсутствии кеша CI может восстановить ранее проверенные связи из успешного запуска 45455551160 только при точном совпадении Git blob идентификаторов каталога, метаданных и импортёра и контрольных SHA-256 обоих файлов. При недоступности артефакта используется штатный импорт. Дополнительные точные связи: Coffee Like (Q55662627, уже указан в исходном Overture), Rostic's (Q3442874, https://commons.wikimedia.org/wiki/File:Текстовой_логотип_сети_Rostic%27s.svg), KFC (Q524757, https://commons.wikimedia.org/wiki/File:KFC_logo_wordmark.svg). Лицензии, атрибуция и сами миниатюры проверяются импортёром; ссылки сами по себе не считаются готовыми логотипами. Пакетный поиск всех остальных брендов сохраняется без порога частоты.

### Единая проверка качества каталога
Отчёт `docs/catalog-quality.json` в артефакте `shodi-brand-coverage` считает фактические карточки приложения: настоящие встроенные фото, доступные и отображаемые логотипы, описания, ссылки OSM и неизвестный статус работы. Ссылки OSM не считаются фотографиями. Полное декодирование всех встроенных растров в Chromium выполняется без сети; APK дополнительно проверяется на побайтовое совпадение HTML с проверенной сборкой. Незавершённый импорт возобновляется с ранее не проверенных брендов, включая одиночные филиалы; старые попытки не блокируют дальнейшие повторы. Кеш логотипов привязан к точному каталогу, связям брендов и правилам проверки в public/brands.js и public/photos.js; при изменении политики импорта, которое делает старые проверки непригодными, необходимо повысить версию префикса кеша. Для названий без QID неоднозначность проверяется по всем точным совпадениям Wikidata, даже если часть совпадений не имеет P154.

### Совместимость с Wikimedia thumbnails (ноябрь 2026)
Импорт и онлайн-фото используют общий строгий валидатор HTTPS URL Commons. Известные аналитические UTM-параметры удаляются, прямые растровые миниатюры используют thumb.wikimedia.org, небольшие исходные PNG/JPEG — upload.wikimedia.org. Другие параметры, произвольные хосты, SVG, редиректы и непроверенные лицензии по-прежнему отклоняются. Ошибки URL теперь содержат диагностический хост/путь и имена параметров. Регрессионные тесты и браузерный mock проверяют ответ API с UTM.

### Расширение офлайн-фотографий
Импорт и интеграция используют единый бюджет 250 проверенных фотографий / 12 МБ декодированных растров, вместо прежнего потолка 100 / 5 МБ. Размер считается по реальным байтам, проверяются сигнатуры PNG/JPEG и прежние лицензионные записи. Интеграция останавливается, если новый импорт удаляет ранее проверенный файл; окончательное количество фото измеряется в каталоге приложения после сборки. Лимит выбран с учётом размера автономной APK, это не обещание наличия 250 подходящих фотографий.

### Дополнительное точное сопоставление
Поиск брендов учитывает варианты регистра и пунктуации, не отменяя проверку неоднозначности и P154. Импорт описаний хранит контрольный SHA списка названий и номера успешных пакетов; ошибочные и непройденные пакеты повторяются. Дополнительные QID из OSM проверяются по точному имени, координатам Wikidata и русскому описанию. Ссылки без подтвержденных данных не считаются покрытием.
