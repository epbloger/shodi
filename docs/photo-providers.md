# Источники фотографий SHODI

## Подключённые открытые источники

- Wikimedia Commons: P18 Wikidata и явные ссылки на файл из OSM. Только проверенная лицензия и авторство, HTTPS, допустимый формат и размер. При сомнении — иллюстрация категории. Сведения о сторонних правах требуют проверки перед коммерческой публикацией.
- OpenStreetMap: © OpenStreetMap contributors, ODbL 1.0 (https://www.openstreetmap.org/copyright). Отдельная адаптированная база public/data/osm-photo-links.js, предоставляемая на тех же условиях. Импорт scripts/import-osm-photo-links.mjs использует Overpass VK Maps (https://maps.mail.ru/osm/tools/overpass/api/interpreter), фильтрует явные File-ссылки и идентификаторы Wikidata, сопоставляет имя и координаты. Данные Overture не перелицензируются. Статистика docs/osm-photo-coverage.json отражает ссылки, а не гарантированное количество доступных фотографий.

## Коммерческие поставщики (пока не подключены)

Яндекс: https://yandex.ru/maps-api/docs/geosearch-api/response.html — документированный ответ стандартного поиска не содержит фото. Требуется отдельное разрешение и документированный интерфейс.
2ГИС: https://docs.2gis.com/api/search/places/reference/3.0/items — has_photos является признаком наличия, а не разрешённой выдачей фото. https://law.2gis.ru/catalog-pay — платный API и отдельные условия сохранения данных. Не использовать внутренние endpoint-ы и рекламные логотипы из служебных полей.

### Запрос поставщику (черновик, не отправлен)

Здравствуйте! Разрабатываем бесплатный Android-гид «Сходи» с рекламной монетизацией, без встроенной карты поставщика. В каталоге около 56 тысяч общественных мест и заведений по России. Нужен официальный API получения фотографий и/или логотипов для конкретной организации по названию, адресу и координатам, отображение миниатюр в собственных карточках с атрибуцией. Просим сообщить, доступен ли такой API, какие права на показ пользовательских и корпоративных фото предоставляются, разрешено ли использование без вашей карты, разрешён ли локальный кеш (размер и срок), какие тарифы, квоты, обязательные ссылки, требования к данным и способы удаления отозванных материалов действуют. Нужна возможность серверного хранения ключа, без передачи секретов в APK.

До получения письменных условий и согласованной стоимости коммерческие источники не включаются. Ключи только в защищённой серверной конфигурации; никакого парсинга сайтов или скрытых API.
