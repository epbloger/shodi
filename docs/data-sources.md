# Источники каталога

## Города

Список городов адаптирован из [справочника DaData / HFLabs](https://github.com/hflabs/city/tree/ae661bffe572880472249097c9b29c42b09650ea), лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). В адаптации оставлены название города, регион и сокращённый идентификатор. Результат в `public/data/cities.js` также распространяется по CC BY-SA 4.0.

## Места

Использована [открытая выборка Yandex Geo Reviews Dataset 2023](https://github.com/yandex/geo-reviews-dataset-2023/tree/8ed84aefeb3976106f89ed1c93c545941e2651f4), лицензия MIT. [Текст лицензии](../public/assets/yandex-reviews-license.txt). Две копии файлов Parquet опубликованы в [архиве AndreyKapusti](https://github.com/AndreyKapusti/geo-reviews-dataset-2023-analytics/tree/80c29106e52971efefd0e35e6cebc392df0739e1).

В выборку входят отзывы за январь — июль 2023 года. Из исходных файлов используются название, адрес, рубрики и оценки для подсчёта среднего и количества отзывов в выборке. Тексты отзывов не считываются скриптом и не распространяются. Наряду с рейтингом учитывается число попавших в выборку отзывов. Отбор чередует категории. Справочник не содержит текущих цен и сведений о том, открыто ли заведение сейчас.

## Обновление данных

Сохраните CSV городов и две части отзывов Parquet указанных ревизий. Для запуска импортера нужен Python с DuckDB 1.5.4.

```sh
python scripts/import-russia.py city.csv geo-reviews-dataset-2023-1.parquet geo-reviews-dataset-2023-2.parquet
```

Контрольные суммы SHA-256 входных файлов:

## Обновление каталога 2026

Новый источник — [Overture Maps Places, выпуск 2026-11-18.0](https://docs.overturemaps.org/blog/2026/11/18/release-notes/). Используем записи от документированных разрешительных поставщиков (без Foursquare), [источники и лицензии](https://docs.overturemaps.org/attribution/), [текст CDLA-Permissive-2.0](../public/assets/overture-license.txt). Изменения: отбор категорий, однозначное сопоставление городов, исключение известных закрытых мест, отбор по confidence. Confidence — оценка уверенности в существовании объекта, не рейтинг посетителей. Дата релиза не означает проверку каждого объекта в этот день. Цены, рейтинги и часы работы не выдумываются. Старые записи сохраняются для маршрутов и отдельно отмеченного архива там, где нет свежей подборки.

Запуск: `pip install duckdb==1.5.4 Unidecode==1.4.0`, затем `python scripts/import-overture.py --release 2026-11-18.0`. GitHub Actions проверяет минимальное покрытие, тесты и сборку до фиксации данных и публикации. Файл docs/current-catalog.json создаётся только после успешного импорта.

### Расширенный каталог

Лимит в 20 мест на город снят. Филиалы с одинаковым названием и разными адресами сохраняются отдельно. Категории чередуются в выдаче. Импорт проверяет минимальное покрытие (500 городов, 15 000 мест, 100 мест и 10 категорий в Санкт-Петербурге) до замены действующей базы. Фактическое количество публикуется в `docs/current-catalog.json`.

### Статусы и покрытие по всем городам

Импорт учитывает первичную и иерархическую категорию, а также явные названия театров и смотровых площадок. Исключаются закрытые и временно закрытые места, а также дубликаты с совпадающими названием и адресом, отмеченные как закрытые разрешённым источником. Статус open означает работу по данным выпуска, а не открытие прямо сейчас; неизвестный статус обозначается отдельно. Архив 2023 года больше не показывается как действующий каталог, но доступен для сохранённых маршрутов. Отчёт docs/catalog-coverage.json содержит все города и все 15 категорий, включая нулевые значения. Источник не гарантирует полноту или актуальность каждой организации.

### Описания мест
Индивидуальные сведения извлекаются из структурированных данных [Wikidata (CC0)](https://www.wikidata.org/wiki/Wikidata:Licensing). Сопоставление только по точному нормализованному названию и координатам в радиусе 180 м; неоднозначные совпадения пропускаются. Карточки показывают источник, а при отсутствии совпадения — честное сообщение. Скрипт обогащения не обращается к пользовательским данным и выполняется только на этапе подготовки каталога.

Запуск: node scripts/enrich-descriptions.mjs. Отдельный workflow Enrich place descriptions формирует проверенный артефакт и отчёт о покрытии, не меняет автоматически исходный каталог и не публикует непроверенные результаты. Импорт может быть частичным из-за лимитов источника. Отчёт содержит число реально сопоставленных мест, а не обещание полного покрытия.

### Фотографии мест
Фото берутся по свойству P18 Wikidata только для совпадений названия и координат. Разрешены CC BY 4.0, CC BY-SA 4.0 и CC0 с указанием авторства, файла и лицензии. Файлы с дополнительными ограничениями пропускаются; логотипы требуют отдельной проверки прав на товарные знаки. Миниатюры JPEG/PNG хранятся локально. Первая партия ограничена 100 файлами и 5 МБ исходных миниатюр; отчёт содержит фактическое покрытие. Дополнительные права на изображённые объекты требуют проверки перед выпуском.
