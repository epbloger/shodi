# Подготовка SHODI к RuStore

## Карточка приложения

| Поле | Значение |
| --- | --- |
| Название | Сходи — куда сходить? |
| Пакет | ru.moorkis.shodi |
| Версия | 2.0.0 (20000) |
| Android | 8.0+, target API 35 |
| Категория | Путешествия (уточнить доступные категории в консоли) |
| Поддержка | helpmoorkis@yandex.ru |
| Реклама | Есть, Yandex Mobile Ads; выбор персонализации |

**Краткое описание:** Офлайн-путеводитель по городам России и планировщик прогулок.

**Полное описание:**

Сходи помогает выбрать интересные места и составить собственный маршрут прогулки. В локальном каталоге 55 716 мест в 574 городах России: музеи, парки, архитектура, кафе и другие категории. Ищите по названию, фильтруйте по интересам, добавляйте остановки и отмечайте посещённые места. Сохраняйте несколько маршрутов и делитесь ими через системное меню Android. Каталог и сохранённые маршруты доступны без интернета. Для внешних карт, дополнительных онлайн-фотографий и рекламы требуется сеть. Описания, изображения и адреса доступны по мере наличия подтверждённых данных; расписание, цены и актуальность адресов следует уточнять у самих мест. Приложение не требует доступа к геолокации, камере и личной галерее.

**Что нового:** Локальный каталог городов России, подборки по категориям, адреса остановок, порционная загрузка карточек, улучшенные мобильные кнопки, управление маршрутами и выбор персонализации рекламы.

## Материалы и загрузка

- Рабочая ветка android-v2. Тестовая сборка: Actions → Android APK → shodi-android-test. Проверить SHA коммита, зелёные задания test и emulator; скачать отчёт shodi-android-security-report.
- Иконка: 512 × 512, PNG или JPEG, непрозрачная, до 3 МБ. Артефакт shodi-rustore-assets содержит экспорт текущей иконки и три предпросмотра встроенного интерфейса. Для телефона подготовить минимум три настоящих скриншота: каталог, карточки выбранного города и сохранённый маршрут. Артефакт shodi-emulator-report содержит фактические Android-скриншоты пройденных этапов. Не выдавать браузерный прототип за системный Android-скриншот.
- Возрастной рейтинг и декларация данных заполняются по реальному контенту и поведению рекламы. Не выбирать рейтинг наугад. Проверить правила RuStore перед отправкой.
- Внести подтверждённые реквизиты в документы public/about.html, privacy.html, terms.html, consent.html, licenses.html; опубликовать политику на публичном HTTPS-адресе. Не использовать заглушки и неподтверждённое имя.
- Следовать docs/android.md для настоящего ключа, рекламных ID и защищённого окружения android-release. Запуск production вручную на android-v2. Загрузить именно подписанный shodi-rustore-apk, не app-debug.apk. Сохранить ключ для будущих обновлений.

## Проверка на телефоне

1. Установить debug APK на чистое устройство Android 8+ и современное Android. Запустить, отказаться от персонализации, открыть «О приложении», перезапустить; выбор должен сохраниться. Проверить отсутствие запросов камеры, галереи, микрофона и геолокации.
2. Выбрать город, категорию, найти место; открыть ещё одну порцию карточек. На телефоне начать с 10, затем 20. Проверить читаемость на узком экране, поворот, светлую и тёмную темы, крупный системный шрифт и клавиатуру.
3. Открыть «Подробнее на картах». Проверить открытие правильного адреса или координат во внешнем приложении. SHODI не содержит карты выбора произвольной точки, обратного геокодирования, камеры или импорта личных фото. Каталожные изображения не требуют разрешений галереи.
4. Добавить два места в маршрут, открыть его, проверить адрес из каталога и ссылку на карте, изменить порядок, отметить посещение, отредактировать остановку, проверить системное меню «Поделиться».
5. В авиарежиме принудительно завершить приложение и снова открыть: каталог, встроенные изображения, адреса и маршруты доступны. Внешние карты и новые онлайн-фото без сети не обещаются.
6. Отменить удаление маршрута, затем подтвердить; перезапустить и проверить отсутствие маршрута. Проверить системное «Настройки → Приложения → Сходи → Хранилище → Очистить данные»: только на тестовой установке, операция необратимо удаляет локальные маршруты и настройки.
7. На реальном устройстве отдельно проверить баннеры, нативное объявление, интервалы межстраничной рекламы, отсутствие перекрытия кнопок, согласие/отзыв, отключение сети. Проверить фактическую обработку SDK до утверждения правовых документов. Не использовать производственные объявления для тестовых кликов.

Официальные требования: https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirements-for-apps и https://www.rustore.ru/help/developers/publishing-and-verifying-apps/publishing-apps . Окончательное решение о модерации принимает RuStore.
