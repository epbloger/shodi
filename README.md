## ✨ Возможности

### 🔎 Найдите место под настроение

- Поиск по 1 117 городам России с подсказками и указанием региона для одноимённых городов.
- Готовые подборки из 5 132 мест в 910 городах.
- Поиск по названию, району или интересам, 15 категорий и сброс фильтров.
- Карточки с описанием, адресом или районом, категорией, оценкой из выборки либо ориентировочной стоимостью — в зависимости от доступных данных.
- Переход в Яндекс Карты для каждого места; если в городе ещё нет подборки, можно открыть поиск достопримечательностей на карте.

### 🗺️ Соберите свой маршрут

- Добавляйте места из каталога в новый или существующий маршрут.
- Создавайте собственные прогулки для любого города, даже вне каталога.
- Указывайте название, город и описание маршрута.
- Добавляйте остановки вручную: название, категория, время на посещение и заметки.
- Редактируйте и меняйте порядок остановок с помощью стрелок.
- Удаляйте отдельные остановки кнопкой с корзиной, а целый маршрут — кнопкой «Удалить маршрут». Перед удалением потребуется подтверждение.
- Управляйте несколькими прогулками: до 30 маршрутов, по 32 остановки в каждом.
- Одно и то же место из каталога не добавляется в выбранный маршрут повторно.

### ✅ Следите за прогулкой

- Отмечайте посещённые места и при необходимости снимайте отметки.
- Смотрите количество остановок, прогресс и суммарное время на посещение.
- Открывайте сохранённые маршруты при следующем запуске.
- Попробуйте готовый демонстрационный маршрут «Суббота у воды»: его можно изменить или удалить.

### 📱 Пользуйтесь где удобно

- Адаптивный интерфейс для компьютера, планшета и телефона.
- Светлая и тёмная темы: переключатель в боковом меню, выбор сохраняется в браузере.
- Без регистрации, паролей и обязательной установки.
- Автоматическое локальное сохранение маршрутов в браузере.
- Возможность пользоваться скачанным файлом без подключения к сети.

## 🧭 Как собрать прогулку

1. Откройте **«Места в городе»**. Начните вводить название города и выберите его из подсказок.
2. Найдите интересные места с помощью поиска и категорий.
3. В поле **«Добавлять в маршрут»** выберите существующую прогулку или **«Создать новый маршрут»**.
4. Нажмите **«В маршрут»** на карточках понравившихся мест.
5. Откройте маршрут, расставьте остановки в удобном порядке, добавьте заметки и время на посещение.
6. Во время прогулки отмечайте пройденные места и отслеживайте прогресс.

Можно начать и с кнопки **«Новый маршрут»** в боковом меню, а затем наполнить его собственными остановками.

> Например: кофе утром → выставка → прогулка по набережной → ужин. Все планы в одном месте.

## ❓ Частые вопросы

<details>
<summary><b>Сервис действительно бесплатный?</b></summary>

Да. Онлайн-версия и скачиваемый HTML-файл доступны бесплатно, без регистрации. Билеты, еда и другие услуги в самих заведениях оплачиваются отдельно.

</details>

<details>
<summary><b>Можно ли пользоваться без интернета?</b></summary>

Да. Скачайте автономный HTML-файл. Каталог, поиск и планировщик работают локально. Для перехода в Яндекс Карты требуется интернет.

</details>

<details>
<summary><b>Где сохраняются мои маршруты?</b></summary>

В локальном хранилище браузера (`localStorage`). Используйте тот же браузер, профиль и адрес сайта или тот же скачанный файл. Очистка данных браузера может удалить маршруты. Некоторые браузеры ограничивают сохранение для локальных HTML-файлов; сервис сообщит, если сохранить изменения не удалось.

</details>

<details>
<summary><b>Синхронизируются ли маршруты между устройствами?</b></summary>

Нет. Облачной синхронизации пока нет. Онлайн-версия и скачанный файл также используют отдельные хранилища и не обмениваются маршрутами автоматически.

</details>

<details>
<summary><b>Можно ли добавить своё место или другой город?</b></summary>

Да. При создании маршрута укажите нужный город и добавьте собственные остановки вручную.

</details>

<details>
<summary><b>Сходи автоматически строит маршрут на карте?</b></summary>

Нет. Вы самостоятельно определяете последовательность остановок. Ссылки «На карте» открывают места из каталога в Яндекс Картах. Суммарное время учитывает только заданное время на остановках, без дороги между ними.

</details>

<details>
<summary><b>Насколько актуальны цены и оценки?</b></summary>

Цены там, где они указаны, ориентировочные. Архивные подборки основаны на открытой выборке отзывов за январь — июль 2023 года; свежие подборки Overture Maps не содержат пользовательских рейтингов или цен. Перед визитом уточняйте стоимость, часы работы и наличие заведения.

</details>

<details>
<summary><b>Как обновить скачанную версию?</b></summary>

Скачайте свежий HTML-файл из [последнего релиза](https://github.com/epbloger/shodi/releases/latest). Учитывайте, что сохранение маршрутов зависит от браузера и расположения файла. Автоматического переноса данных между файлами нет.

</details>

## 🛠️ Для разработчиков

<details>
<summary><b>Технологии и сборка из исходников</b></summary>

HTML, CSS и JavaScript без фронтенд-фреймворков. Сборка — esbuild, тестирование — Node.js Test Runner, хостинг — GitHub Pages.

Для сборки из исходников понадобятся Node.js 24 и npm:

```bash
git clone https://github.com/epbloger/shodi.git
cd shodi
npm ci
npm test
npm run build
```

Откройте `dist/shodi.html` в браузере — это готовая автономная версия.

| Путь | Назначение |
| :--- | :--- |
| `public/` | Интерфейс, стили, каталог, логика и ресурсы |
| `public/data/` | Данные городов и мест |
| `scripts/build.mjs` | Сборка единого HTML-файла |
| `scripts/import-russia.py` | Импорт каталога |
| `tests/` | Автоматические тесты |
| `.github/workflows/` | Публикация сайта и релизов |
| `dist/shodi.html` | Результат локальной сборки |

Сайт публикуется автоматически после изменений в ветке `main`. Скачиваемый файл публикуется отдельно при выпуске версии.

</details>
