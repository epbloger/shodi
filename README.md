# Сходи

Городской путеводитель для тех, кто хочет куда-нибудь сходить, но пока не решил куда.

**[Скачать «Сходи»](https://github.com/epbloger/shodi/releases/latest/download/shodi.html)** · [Посмотреть выпуск](https://github.com/epbloger/shodi/releases/latest)

Откройте скачанный файл в браузере. Можно сразу выбрать город и собирать прогулку.

![Главный экран «Сходи» с каталогом мест Екатеринбурга](docs/preview.webp)

## Найдите место под настроение

Кофе и спокойная прогулка, выставка, театр, вечерний концерт или занятие для всей семьи. В «Сходи» **95 мест в пяти городах** — Екатеринбурге, Москве, Санкт-Петербурге, Казани и Нижнем Новгороде.

Есть **15 категорий**, включая музеи, кофейни, рестораны, парки, смотровые, книжные места, театры, рынки, бары и активный отдых. Ищите по названию, району или интересу. В карточке видны описание, ориентир по цене или среднему чеку и ссылка **«На карте»**.

## Соберите прогулку

1. Выберите город и категорию.
2. Нажмите **«В маршрут»** на карточке места. Можно выбрать существующую прогулку или создать новую.
3. Откройте маршрут, расставьте остановки и отмечайте их по мере посещения.

Маршруты хранятся в вашем браузере. Чтобы открыть их позже, используйте тот же файл и профиль браузера. Ссылки **«На карте»** открывают Яндекс Карты. Цены в карточках рассчитаны как ориентир на человека. Актуальный тариф и часы работы уточняйте перед визитом.
