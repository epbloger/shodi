# Тихий маршрут

Планировщик прогулок для выходных. Соберите места в нужном порядке, прикиньте время на остановках и отмечайте посещённые места по ходу прогулки. Для знакомства с интерфейсом есть маршрут «Суббота у воды» по Екатеринбургу.

![Планировщик с примером маршрута по Екатеринбургу](docs/preview.webp)

## Что можно сделать

- Создать маршрут, указать город и оставить описание.
- Добавить остановки с категориями, временем и заметками.
- Поменять порядок остановок стрелками и отмечать посещённые места.
- Просмотреть суммарное время на остановках и прогресс прогулки.
- Отредактировать или удалить маршрут и отдельные остановки. Удаление нужно подтвердить.

## Как запустить

Для локального запуска понадобится Python 3. Откройте [страницу репозитория](https://github.com/epbloger/weekend-atlas), нажмите **Code → Download ZIP** и распакуйте архив. Можно также скачать проект через Git.

```sh
git clone https://github.com/epbloger/weekend-atlas.git
cd weekend-atlas
```

Откройте терминал в папке проекта. В ней должны быть `README.md` и папка `public`. Выполните одну команду для вашей системы.

**Windows**

```cmd
py -3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

**macOS и Linux**

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

Откройте **http://127.0.0.1:4173** в браузере. Чтобы выключить локальный сервер, нажмите **Ctrl+C** в терминале. Для работы приложения достаточно запустить этот сервер и открыть страницу. Шрифты, изображение и код входят в проект.

## Как хранится информация

Маршруты сохраняются в браузере через `localStorage`. Откройте приложение по тому же адресу и в том же профиле браузера, чтобы продолжить с сохранёнными данными. Очистка данных сайта удаляет маршруты. Если браузер блокирует сохранение, приложение показывает сообщение и оставляет изменения доступными в текущей вкладке.

## Проверки

Для автоматических проверок модели данных нужен Node.js 20 или новее. Из папки проекта выполните:

```sh
npm test
```

Тесты покрывают валидацию полей и сохранённого JSON, дубликаты записей, порядок остановок и расчёт времени. В Chromium также проверены создание, редактирование, удаление, отметка посещения, сохранение после перезагрузки и работа на узком экране.

При проверке безопасности я проверил вывод пользовательского текста, чтение повреждённых данных и сетевые запросы. Названия и заметки выводятся как текст. Политика CSP ограничивает загрузку ресурсов источником страницы и блокирует внешние запросы приложения. В браузерном прогоне внешних запросов не было.

## Файлы проекта

- `public/index.html` и `public/styles.css` — интерфейс и адаптивная вёрстка.
- `public/app.js` — работа форм, сохранение и обновление интерфейса.
- `public/routes.js` — модель маршрутов и проверка данных.
- `tests/routes.test.js` — тесты модели.

Шрифты Manrope и PT Serif распространяются по SIL Open Font License. Тексты лицензий лежат рядом со шрифтами в `public/assets`. Изображение набережной — сгенерированная иллюстрация для демонстрационного маршрута.
